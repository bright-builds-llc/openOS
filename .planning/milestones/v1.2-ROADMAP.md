# Milestone v1.2: Notes, Browser & Platform Growth

**Status:** ✅ SHIPPED 2026-04-11  
**Phases:** 16-22  
**Total Plans:** 20

## Overview

openOS `v1.2` expanded the project from the first believable multi-app shell into a more useful daily system. `Notes` gained local search and folder organization, `Browser` gained truthful direct URL entry, the internal app-platform layer became a contributor-facing submission and catalog surface, and the milestone closed with one repo-native verification command plus two focused audit-debt cleanup phases.

## Milestone Summary

**Decimal Phases:**

- None.

**Key Decisions:**

- Keep Notes local-first while proving search and organization before sync/accounts.
- Broaden Browser through truthful direct entry rather than fake Safari-parity claims.
- Make submitted apps repo-driven and metadata-first before attempting arbitrary installation.
- Close milestone audit gaps with narrow hardening phases instead of reopening broad product scope.

**Issues Resolved:**

- Notes is no longer limited to a flat local notebook.
- Browser can now accept typed destinations while keeping fallback behavior honest.
- The project now has one real in-product app catalog sourced from reviewed submission metadata.
- Submitted-manifest drift can no longer silently bypass validation or catalog visibility.
- Browser grid and dock launchers no longer risk split state by default.

**Issues Deferred:**

- Notes sync/accounts and richer editing remain deferred until the local information model settles.
- Browser tabs and more persistent browsing state remain deferred until the truthfulness bar can be preserved.
- Arbitrary app installation remains deferred until the reviewed submission/catalog path matures further.

**Technical Debt Incurred:**

- Submitted manifest registration is still manual, even though validator drift is now fail-closed.
- Browser still has separate launcher ids for one canonical runtime identity, which is intentional but requires discipline in downstream code.
